# 本地启动

请双击 **`打开黄金替罪芙.bat`** 启动游戏。它会自动打开浏览器，并进入：

```text
http://127.0.0.1:8765/GameEdition2/（若 8765 已被占用，启动器会自动换用下一个可用端口）
```

游戏运行期间请保持弹出的命令窗口开启；关闭该窗口或按 `Ctrl + C` 即可停止本地服务器。不要直接通过 `file:///` 打开 `index.html`，否则关卡解锁和“下一关”通信可能不稳定。

# 黄金替罪芙 · 正式试玩版（基础记录 01—05 / 试炼记录 15—17）

这是第 1—5 关基础教学与第 15—17 关替罪芙试炼组成的本地可玩章节版。打开 `index.html` 后：

- 从第 1 关开始；
- 依次完成 1 → 2 → 3 → 4 → 5，随后解锁第 15 关；
- 第 6—14 关当前不在试玩版中显示；
- 每关完成后自动解锁下一实际关卡；
- 可使用“跳过当前关”直接解锁下一关；
- 浏览器会通过本地存储保存通关和解锁进度；
- 可以在页面中清除进度重新游玩；
- 单关页包含“撤销一步”“下一步提示 H”“重新开始 R”；提示只显示标准答案的下一步方向，不会自动移动。
- 关卡地图采用高 DPI Canvas 渲染，实时验证面板固定在左侧，只展示替罪芙、钥匙、压板三项；
- 每关底部会清楚显示本关目标；基础教学会按机制逐步加入钥匙、压力板与传送门条件。

## 本地试玩

推荐直接双击 `GameEdition2/打开黄金替罪芙.bat`；也可以在 `GameEdition2` 目录运行：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\start-game-server.ps1 -NoBrowser -Port 8765
```

访问：

```text
http://127.0.0.1:8765/GameEdition2/（若 8765 已被占用，启动器会自动换用下一个可用端口）
```

## 当前传送门规则

- 任意同字母、不同大小写的标记均为双向传送门（如 `M ↔ m`、`N ↔ n`、`T ↔ t`）；芙、替罪芙与箱子遵循同一规则。
- 传送出口被任何对象占据时，本次传送无效。
- 推箱子进入传送门时，箱子会传送，芙只移动到箱子原先所在格，不会被连带传送。
- 通关后会弹出结算界面；父页面会保存完成状态并解锁下一关，玩家点击“下一关”后才切换关卡。
