# 黄金替罪芙

一个纯静态 HTML / Canvas 解谜闯关试玩版：芙需要收集钥匙、压住压板并抵达 Exit；第 6—10 关加入延迟复现行动的替罪芙机制。

## 直接打开游玩（无需本地服务）

任选其一：

1. 双击 `打开黄金替罪芙.bat`；
2. 或直接双击 `index.html`。

游戏已兼容 `file:///` 直接打开：关卡 iframe、通关解锁、下一关、跳关和本机进度保存均可使用。若浏览器阻止本地文件访问，请使用 Chrome、Edge 或在浏览器中选择“允许本地文件访问”。

## 当前关卡

- 基础教学：第 1—5 关（移动、钥匙、箱子、压板、传送门）
- 替罪芙试炼：第 6—10 关（延迟复现、双替罪芙、箱子与传送门）
- 高难终局：第 11—12 关

## 操作

- 移动：方向键 / WASD
- 撤销：`Z`
- 标准答案下一步提示：`H`
- 重新开始：`R`

## 通用规则

- 需要收集全部钥匙、压住全部压板后，再由芙抵达 Exit。
- 压板可由芙、替罪芙或箱子压住。
- 传送门为同色双向配对；芙、替罪芙和箱子均可通过。
- 推箱子进入传送门时，箱子传送，芙停在箱子原本所在格。
- 替罪芙可以踩压板、通过传送门；不能拿钥匙或推动箱子。
